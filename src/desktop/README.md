# HELM Desktop Runtime

هذه الطبقة تعمل فقط داخل Tauri، بينما تظل نسخة المتصفح متصلة مباشرة بـSupabase.

- `bridge.js`: جسر أوامر Tauri وقاعدة SQLite.
- `base44DesktopClient.js`: وكيل Offline-First للكيانات والمزامنة.
- `DesktopAwareStatusBar.jsx`: حالة الاتصال وقائمة العمليات المعلقة.

قواعد التشغيل:

1. لا تُحفظ مفاتيح Supabase السرية داخل SQLite.
2. العمليات غير المتزامنة تحفظ في `sync_outbox` بترتيب إنشائها.
3. تستخدم المزامنة `upsert` للحفاظ على معرف السجل نفسه بين الجهاز والسحابة.
4. نسخة الويب لا تستدعي أوامر Tauri ولا تنشئ قاعدة محلية.
